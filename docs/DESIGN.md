# 设计说明

## 视觉方向

TZBox 以温暖留白、清晰工具层级和克制的 Neumorphism 组织界面。参考 [Claude 产品页面](https://claude.com/product/overview) 的温暖留白，以及 [Surge](https://nssurge.com/) 的工具信息层级，落到时区代理的具体任务：先看当前时间与目标，再处理应用。

- 暖纸白与温灰构成浅色画布，陶土色用于主要操作和选中状态。
- 柔和的双向阴影区分表面，内凹状态表示当前选择；文字、边界与标签承担主要辨识工作。
- 侧栏筛选保持简短，主区域集中显示目标大时钟、系统时间对照和紧凑的应用行。
- 深色模式使用对应的动态表面与文字颜色；高对比度模式保留清晰边界。
- 运行、未受管、待重新应用和错误状态均用明确文字表达，不只依赖颜色。

## 图标与资源

图标由深蓝灰陶瓷底座、象牙白地球钟面和陶土色中心组成。钟面表达同一个真实时刻，地球线条表达时区转换；透明外围用于 macOS 图标呈现。

最终源图为 [AppIcon.png](../Assets/AppIcon/AppIcon.png)。生成来源与完整提示词保存在 [GENERATION.md](../Assets/AppIcon/GENERATION.md)。打包只使用系统工具缩放、转换格式，不重画源图、不添加额外底板。

`scripts/build-icon.sh` 从源 PNG 生成 16、32、128、256、512 点的 1× / 2× 图像，汇合成包含最大 1024 像素图像的 ICNS。应用包同时携带 `AppIcon.png` 与 `AppIcon.icns`，分别供界面品牌显示及系统图标使用。

## 交互约定

目标时区与每个应用的实际启动时区分开展示。修改目标不会假称运行中的应用已经切换，未应用的运行实例保留真实状态，等待用户确认正常重启。

主要操作以当前状态变化：未运行时应用并启动，已有实例时确认重启；恢复系统时区通过正常退出并去除启动环境中的 `TZ` 完成。应用的退出或保存提示优先，TZBox 不强杀应用。

窗口关闭后保留菜单栏入口。错误提示说明可以采取的动作；损坏配置与运行记录通过显式备份恢复，启动成功与时间行为验证分开记录。界面优化不改变这些代理边界。
